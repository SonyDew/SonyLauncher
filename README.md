# SonyLauncher

A Windows launcher for Minecraft: Java Edition, built with Tauri, Rust, React and TypeScript.

## Features

- Separate instances for your worlds, mods and settings.
- Vanilla, Fabric, Quilt, Forge and NeoForge support.
- Automatic selection of compatible mod loader versions and Java runtimes.
- Mod management through Modrinth.
- Download progress, cancellation and file verification.
- Microsoft sign-in with Minecraft: Java Edition ownership verification.

SonyLauncher is in development. Microsoft API approval is pending, so Microsoft sign-in is not yet fully available.

## Privacy

Settings and game data stay on your computer. Microsoft sign-in opens in your browser, and refresh tokens are stored in Windows Credential Manager. SonyLauncher does not collect analytics or automatically upload logs.

Read the [privacy policy](PRIVACY.md) for details.
